# HoverTeX

**HoverTeX** is a Chrome extension that lets you instantly copy LaTeX from rendered math equations on the web ✨. Instead of retyping formulas, simply hover over an equation and click to copy the original LaTeX source.

HoverTeX works seamlessly across popular math-heavy websites like **Wikipedia, ChatGPT, Stack Exchange**, and many educational or documentation pages that use KaTeX or MathJax.

## ✨ Features

- 🧮 Copy LaTeX from **KaTeX** and **MathJax** (v2–v4) equations  
- 🌐 Supports **Wikipedia math images** and Wiki-based sites  
- 🖱️ Simple hover + click interaction — no menus or shortcuts  
- ⚡ Fast and lightweight with zero setup  
- 🔒 Privacy-friendly: no tracking, no data collection  

## 🛠️ Tech Stack

- 🧩 **Chrome Extensions API (Manifest V3)**  
- 📜 **JavaScript (Vanilla)** for content scripts and page injection  
- 📐 **MathJax API** for extracting LaTeX from rendered equations  
- 🎨 **CSS** for hover overlay and UI feedback  

## 🚀 Future Enhancements

- ⌨️ Optional keyboard shortcut to copy LaTeX
